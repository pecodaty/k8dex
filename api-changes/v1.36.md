# Kubernetes API changes for v1.36

Compared with: v1.35

## Added

- admissionregistration.k8s.io/v1 mutatingadmissionpolicies (MutatingAdmissionPolicy)
- admissionregistration.k8s.io/v1 mutatingadmissionpolicybindings (MutatingAdmissionPolicyBinding)
- resource.k8s.io/v1alpha3 resourcepoolstatusrequests (ResourcePoolStatusRequest)
- resource.k8s.io/v1beta2 devicetaintrules (DeviceTaintRule)
- scheduling.k8s.io/v1alpha2 podgroups (PodGroup)
- scheduling.k8s.io/v1alpha2 workloads (Workload)

## Removed

- scheduling.k8s.io/v1alpha1 workloads (Workload)

## Changed

- None.

## Added request schemas

- io.k8s.api.admissionregistration.v1.MutatingAdmissionPolicy

- io.k8s.api.scheduling.v1alpha2.Workload
