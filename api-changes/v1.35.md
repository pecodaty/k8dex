# Kubernetes API changes for v1.35

Compared with: v1.34

## Added

- certificates.k8s.io/v1beta1 podcertificaterequests (PodCertificateRequest)
- scheduling.k8s.io/v1alpha1 workloads (Workload)
- storagemigration.k8s.io/v1beta1 storageversionmigrations (StorageVersionMigration)

## Removed

- certificates.k8s.io/v1alpha1 podcertificaterequests (PodCertificateRequest)
- storage.k8s.io/v1alpha1 volumeattributesclasses (VolumeAttributesClass)
- storagemigration.k8s.io/v1alpha1 storageversionmigrations (StorageVersionMigration)

## Changed

- resource.k8s.io/v1alpha3 devicetaintrules (DeviceTaintRule)

## Added request schemas

- io.k8s.api.certificates.v1beta1.PodCertificateRequest
- io.k8s.api.scheduling.v1alpha1.Workload
- io.k8s.api.storagemigration.v1beta1.StorageVersionMigration

## Removed request schemas

- io.k8s.api.certificates.v1alpha1.PodCertificateRequest
- io.k8s.api.storage.v1alpha1.VolumeAttributesClass
- io.k8s.api.storagemigration.v1alpha1.StorageVersionMigration

## Changed request schemas

- io.k8s.api.resource.v1alpha3.DeviceTaintRule
