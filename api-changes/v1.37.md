# Kubernetes API changes for v1.37

Compared with: v1.36

## Added

- certificates.k8s.io/v1 clustertrustbundles (ClusterTrustBundle)
- certificates.k8s.io/v1 podcertificaterequests (PodCertificateRequest)
- lifecycle.k8s.io/v1alpha1 evictionrequests (EvictionRequest)
- lifecycle.k8s.io/v1alpha1 evictions (Eviction)
- resource.k8s.io/v1 devicetaintrules (DeviceTaintRule)
- scheduling.k8s.io/v1alpha3 compositepodgroups (CompositePodGroup)
- scheduling.k8s.io/v1alpha3 podgroups (PodGroup)
- scheduling.k8s.io/v1alpha3 workloads (Workload)
- scheduling.k8s.io/v1beta1 podgroups (PodGroup)
- scheduling.k8s.io/v1beta1 workloads (Workload)
- storagemigration.k8s.io/v1 storageversionmigrations (StorageVersionMigration)

## Removed

- certificates.k8s.io/v1alpha1 clustertrustbundles (ClusterTrustBundle)
- networking.k8s.io/v1beta1 ipaddresses (IPAddress)
- networking.k8s.io/v1beta1 servicecidrs (ServiceCIDR)
- scheduling.k8s.io/v1alpha2 podgroups (PodGroup)
- scheduling.k8s.io/v1alpha2 workloads (Workload)
- storage.k8s.io/v1beta1 volumeattributesclasses (VolumeAttributesClass)

## Changed

- storage.k8s.io/v1 csinodes (CSINode)
