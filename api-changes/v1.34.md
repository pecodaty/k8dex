# Kubernetes API changes for v1.34

Compared with: v1.33

## Added

- admissionregistration.k8s.io/v1beta1 mutatingadmissionpolicies (MutatingAdmissionPolicy)
- admissionregistration.k8s.io/v1beta1 mutatingadmissionpolicybindings (MutatingAdmissionPolicyBinding)
- certificates.k8s.io/v1alpha1 podcertificaterequests (PodCertificateRequest)
- resource.k8s.io/v1 deviceclasses (DeviceClass)
- resource.k8s.io/v1 resourceclaims (ResourceClaim)
- resource.k8s.io/v1 resourceclaimtemplates (ResourceClaimTemplate)
- resource.k8s.io/v1 resourceslices (ResourceSlice)
- storage.k8s.io/v1 volumeattributesclasses (VolumeAttributesClass)

## Removed

- admissionregistration.k8s.io/v1beta1 validatingadmissionpolicies (ValidatingAdmissionPolicy)
- admissionregistration.k8s.io/v1beta1 validatingadmissionpolicybindings (ValidatingAdmissionPolicyBinding)
- resource.k8s.io/v1alpha3 deviceclasses (DeviceClass)
- resource.k8s.io/v1alpha3 resourceclaims (ResourceClaim)
- resource.k8s.io/v1alpha3 resourceclaimtemplates (ResourceClaimTemplate)
- resource.k8s.io/v1alpha3 resourceslices (ResourceSlice)

- None.
